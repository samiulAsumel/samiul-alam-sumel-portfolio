# Prompt Templates for Port Projects

## Template 1: Component creation

"You are senior [React/HTML/CSS] developer,
Project: Mongla Port vessel tracking system.
Task: Create [specific component] that [does what].
Data: [vessel has {name, status, berth, IMO}].
Constraints: TypeScript, Tailwind CSS, no external libraries.
Output: Code only, no explanation."

## Template 2: Bug Fix

"You are debugging a management web app.
Here is my code: [paste code]
Problem: [exact error message or wrong behavior]
Expected behavior: [what should happen]
What i already tried: [what you did]
Fix only the specific problem, don't rewrite everything."

## Template 3: Code Review

"Review this code for a port tracking app:
[paste code]
Check for: 1) bugs, 2) performance issues, 3) best practices
Format: List issues with line numbers and fixes."

## Template 4: Architecture Question

"I'm building a port SaaS with:

- Frontend: Next.js
- Backend: Node/Express
- Database: MongoDB
  Question: [specific architecture question]
  Keep answer focused on my stack."
