# AI Developer Workflow

## The 4-Step Process

### Step 1: PRD (Product Requirements Document)

- What problem am I solving?
- Who are the users?
- What are the core features?
- What is out of scope?

### Step 2: Spec (Tecnical Specification)

- What components/files will I create?
- What data structures do I need?
- What APIs/endpoints?

### Step 3: Prompt AI Effectively

Formula: [Role] + [Context] + [Task] + [Constraints] + [Output Format]

- Always give context about the project
- Always specify tech stack
- Ask for one thing at a time
- Never ask "build my entire app"

### Step 4: Review before Commit

- Read every line of AI-generated code
- Understand WHY it's written that way
- Test in manually
- Only then commit to GitHub

## Common Mistakes

1. Vague prompts → Vague code
2. Copy-paste without understanding → can't debug later
3. No PRD → scop creep, confusion
4. Trusting AI blindly → bugs in production
