# PRD (Product Requirements Documents): Port Cargo Status Website

**Version:** 1.0
**Date:** 15/06/2024
**Author:** Md. Samiul Alam Sumel

---

## Problem Statement

Cargo Status in Mongla Port now track manually,
Need a digital system which shows vessel and cargo status.

## Target users

- Port Operations Officer
- Cargo agent
- Shipping Company Representative

## Core Features (MVP)

1. Vessel list with status (arrived / expected / departed)
2. Cargo manifest table per vessel
3. Berth availability display
4. Cargo booking form

## Technical Requirements

- HTML + CSS only (no JavaScript yet)
- Mobile responsive
- Port color theme: Navy (#1e3a5f), Orange (#f97316)

## Out of scope (v1)

- Real-time data
- User login
- Backend/database
- payment

## Success Criteria

- All 4 features visible on screen
- Works on mobile
- Deployed on github pages
